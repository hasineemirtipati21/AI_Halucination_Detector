# AI Hallucination and Citation Verification System

## 📌 Overview
Generative AI models are increasingly used for research, learning, and decision-making.  
However, a major limitation of these models is **hallucination**—the generation of factually incorrect information with high confidence.

An even more critical issue is the creation of:
- Fake citations
- Non-existent research papers
- Invalid or broken reference links

These issues reduce trust in AI-generated content and can lead to **misinformation, legal risks, and ethical concerns**.

This project aims to **detect, flag, and verify factual claims and citations generated by AI models**, helping users identify reliable and unreliable AI-produced information.

---

## 🎯 Problem Statement
AI-generated content often:
- Presents incorrect facts confidently
- References non-existent journals, authors, or papers
- Provides links that cannot be verified

Users currently lack an easy way to **verify the authenticity of AI-generated claims and citations**.

---

## 💡 Proposed Solution
We build a **web-based AI hallucination and citation verification system** that:

- Analyzes AI-generated text
- Detects factual claims
- Verifies citations using trusted sources
- Flags unreliable or unverifiable references
- Provides confidence indicators for users

## ⚙️ System Architecture
1. User submits AI-generated content
2. System extracts factual claims and citations
3. Citations are checked against trusted databases
4. Claims are verified using external sources
5. Results are classified as:
   - ✅ Verified
   - ⚠️ Uncertain
   - ❌ Hallucinated
6. Final report is shown to the user

---

## 🚀 How It Works
1. Paste AI-generated text into the website
2. Click **Verify Content**
3. System analyzes claims and citations
4. Verification results are displayed with flags
5. Users can make informed decisions
